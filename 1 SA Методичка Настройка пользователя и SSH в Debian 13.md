Методичка: Настройка пользователя и SSH в Debian 13

Шаг 1: Получение прав администратора (sudo)

В Debian по умолчанию обычный пользователь не может менять систему.

- **Команда:** `su -` (войти под root, нужен пароль, созданный при установке).
- **Команда:** `usermod -aG sudo имя_пользователя` (добавить пользователя в группу «доверенных»).
- **Зачем:** Чтобы иметь возможность устанавливать программы через `sudo`.
- **Важно:** После этого нужно **перезагрузить** компьютер или перезайти в сессию.

---

Шаг 2: Создание рабочего пользователя

- **Команда:** `sudo adduser developer`
- **Что происходит:** Создается пользователь, его домашняя папка (`/home/developer`) и запрашивается пароль.
- **Зачем:** В Linux небезопасно работать под root или админом постоянно. Для учебы и работы лучше иметь отдельного пользователя.

---

Шаг 3: Генерация SSH-ключей

Это создание твоего уникального «цифрового паспорта» для входа на другие серверы (например, GitHub).

- **Команда:** `ssh-keygen -t ed25519`
- **Разбор:**
    - `ed25519` — самый современный и быстрый алгоритм (Debian 13 его обожает).
    - Система создаст два файла в папке `~/.ssh/`:
        1. `id_ed25519` — **Приватный ключ** (Твой паспорт, никому не показывай!).
        2. `id_ed25519.pub` — **Публичный ключ** (Его мы отдаем сервисам).

---

Шаг 4: Безопасность и проверка

- **Команда:** `chmod 400 ~/.ssh/id_ed25519` — закрываем доступ к приватному ключу для всех, кроме тебя.
- **Команда:** `cat ~/.ssh/id_ed25519.pub` — выводит текст ключа на экран, чтобы его скопировать.

---

Шаг 5: Привязка к GitHub (Deploy Keys)

1. Копируешь текст из терминала (начинается с `ssh-ed25519`).
2. Идешь в настройки репозитория на GitHub -> **Deploy Keys** -> **Add deploy key**.
3. **Allow write access:** Ставь галочку, если хочешь не только скачивать, но и отправлять свой код в облако.

---

Шаг 6: Проверка связи

Самый ответственный момент, который мы только что сделали.

- **Команда:** `ssh -T git@github.com`
- **На вопросы:** Пишем `yes` (чтобы компьютер запомнил сервер) и нажимаем **Enter** (если ключ без пароля).
- **Успех:** Сообщение `Hi [имя]! You've successfully authenticated`.

---

💡 Полезные шпаргалки по командам:

- `ls -la` — показать все файлы (включая скрытые настройки с точкой в начале).
- `ip a` — проверить свой IP и имя сетевой карты.
- `ping -c 4 8.8.8.8` — проверить, есть ли интернет.
- `su - developer` — быстро переключиться на пользователя в терминале.
