Методичка: Веб-разработка и Git в Debian 13 (Часть 2)

1. Подготовка папки для проектов

В Linux веб-проекты традиционно хранятся в `/var/www`. По умолчанию прав на запись туда у обычного пользователя нет.

- **Создание папки:**
    
    bash
    
    ```
    sudo mkdir -p /var/www
    ```
    
    Используйте код с осторожностью.
    
- **Настройка прав (владелец):** Делаем системного пользователя веб-сервера (`www-data`) владельцем.
    
    bash
    
    ```
    sudo chown www-data:www-data -R /var/www
    ```
    
    Используйте код с осторожностью.
    
- **Доступ для группы:** Разрешаем участникам группы `www-data` (в которую мы добавили твоего пользователя) записывать файлы.
    
    bash
    
    ```
    sudo chmod -R 775 /var/www
    ```
    
    Используйте код с осторожностью.

2. Установка инструментов

Если команды `git` нет в системе, её нужно установить из официальных репозиториев.

bash

```
sudo apt update
sudo apt install git -y
```

Используйте код с осторожностью.

---

3. Настройка личности (Git Config)

Перед первым сохранением нужно представиться системе, чтобы Гит знал, кто автор кода.

bash

```
git config --global user.name "Имя Фамилия"
git config --global user.email "your_email@example.com"
```

Используйте код с осторожностью.

---

4. Клонирование проекта (Download)

Чтобы скачать свой проект с GitHub на компьютер:

1. Перейди в папку: `cd /var/www`
2. Клонируй: `git clone git@github.com:логин/репозиторий.git`

---

5. Цикл разработки (Изменение -> Публикация)

Этот цикл ты будешь повторять тысячи раз. Он состоит из трех обязательных шагов:

**Шаг А: Подготовка (Add)**  
Гит не следит за всеми файлами сразу. Ты должен явно сказать, какие изменения хочешь сохранить.

bash

```
git add название_файла.txt
# или добавить всё сразу:
git add .
```

Используйте код с осторожностью.

**Шаг Б: Сохранение (Commit)**  
Создаем «точку восстановления» с описанием того, что было сделано.

bash

```
git commit -m "Краткое описание правок"
```

Используйте код с осторожностью.

**Шаг В: Отправка в облако (Push)**  
Твои изменения пока только на твоем компьютере. Чтобы они появились на GitHub:

bash

```
git push origin main
```

Используйте код с осторожностью.

_(Здесь система может запросить пароль от твоего SSH-ключа)._

---

💡 Короткая шпаргалка по командам этой части:

- **`pwd`** — «Где я?» (показывает полный путь к текущей папке).
- **`ls -F`** — показать файлы и пометить папки символом `/`.
- **`git status`** — проверить, какие файлы изменены, а какие еще не добавлены в корзину.
- **`echo "текст" > файл.txt`** — быстро создать файл с текстом внутри.
